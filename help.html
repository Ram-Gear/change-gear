What the app does

Ask Grok about this

Change Gear works out the change gears for gear hobbing machines: the index ratio, the differential ratio for helical gears, feed ratios, and hob RPM and cutting time. It replaces the old RAM-GEAR BASIC menu program and gives exactly the same numbers for the routines kept from it (FD-500 Overton, Fauter, TOS FO-10, hob RPM & cutting time).

For every ratio it searches the gears you really have (a gear inventory per machine) and lists the best A/B × C/D combinations with their error. You can add your own machines from their constants and formulas.

Everyone signs in with their QC Form username and PIN. Viewers can calculate and look at everything; admins can also add, change, lock and delete machines, gear lists and presets. Machines, gear lists and presets are shared by every PC; machine manuals (PDFs) are shared too once the shared manual storage is set up; until then they stay on the PC they were attached on.

The screens

Ask Grok about this
  • Sign-in: username and PIN, the same as the QC Form.
  • Original program (menu, top): the built-in routines from the old BASIC program. They cannot be changed, only copied.
  • My machines: machines added by an admin. "None yet" means the shared database has no added machines. Admins see + Add a machine; everyone else sees a greyed 🔒 Sign in as admin to add machines line.
  • Machine page: the input form, Calculate, the results, and the gear matches for each gear train, plus index presets and the manual.
  • Gear inventories: every gear list (tooth count, how many, note), with CSV import/export.
  • Import / export: back up or restore machines and gear lists as JSON, and the one-time upload of data saved before logins.
  • Formula help (in the app) and this page.

Common tasks, step by step

Ask Grok about this

Sign in

Ask Grok about this
  1. Open the app.
  2. Type your QC Form username and your PIN, then click Sign in.
  3. Your name and role (admin or viewer) show at the top right. Sign out is next to them.

Calculate on a built-in routine

Ask Grok about this
  1. Click the routine under Original program: (3) FD-500 Overton, (4) Fauter, (7) TOS FO-10 or (9) Hob RPM & cutting time.
  2. Fill in every box. The grey "e.g." text is only an example; Fill blanks with example values copies the examples in. Pick inch or metric where asked.
  3. Click Calculate. A box with a red border means that value is missing or not a number.
  4. The ratios show in the Results box. Below them are the gear matches A/B × C/D, best first, with their error. The TOS FO-10 also needs the number of teeth (z) for its index ratio 24 × starts ÷ z.
  5. Print sheet prints the job.

Example: TOS FO-10, helix 30°, module 8, 1 start, metric gives the differential ratio .7460438; z = 40 gives the index ratio .6.

Gear inventories and CSV upload

Ask Grok about this
  1. Admins: on a machine page click Edit index gears or Edit differential gears, or open Gear inventories and click + New inventory.
  2. Type tooth counts in Quick add, e.g. 20, 24, 30 x2, 40-48 ("x2" = two of them, "40-48" = every count from 40 to 48), or edit the table: tooth count, quantity, note.
  3. Import CSV: columns teeth, qty, note (qty defaults to 1; a header row is optional; comma or semicolon; a single column of tooth counts also works). Check the preview, then pick Replace my list or Add to my list. Download sample CSV gives a file to fill in.
  4. Click Save. The gear search only uses gears in the list and never uses more of a gear than you have.

Index presets

Ask Grok about this

A preset is a saved index gear set for one tooth count z. When the part's z matches, the preset is shown first, marked Preset.

  1. Admins: on the machine page, under Index gear presets, click + Add preset, enter z and A, B (and C, D for a 4-gear set), then Save presets. Or click Save as preset next to a search result.
  2. Presets can also be imported/exported as CSV with columns z, A, B, C, D, note.

For a prime z such as 101 nothing smaller divides into it, so the set must include a 101-tooth gear (e.g. 24/101). The app reminds you when that happens.

Machine manuals (PDF)

Ask Grok about this
  1. Admins: on the machine page click Machine Manual (top row, beside Delete machine) or Attach manual (PDF) and pick the file.
  2. Anyone signed in: Machine Manual opens it.

The PDF is kept in the shared RAM-GEAR manual storage (private, signed-in users only) with a copy in the browser. If the shared storage is not set up yet the machine page says so and the PDF stays in that PC's browser; admins can later upload it with Upload to shared storage (machine page) or Upload manuals to shared storage (Import / export).

Add a machine (admin)

Ask Grok about this
  1. Click + Add a machine.
  2. Give it a name and type its index constant and differential constant. The formulas are already built: index = constant × K ÷ Z, and a Fauter / FD-500 style differential. Remove the one the machine does not have.
  3. Pick each train's gear list (by default the machine gets its own list, starting with one of each 20-88).
  4. The right-hand box checks the formulas and previews them with the example values. Click Save machine.
  5. Different formulas: open Advanced at the bottom (see the formula guide below).

Verify & lock (admin)

Ask Grok about this

New machines are a Draft. When its results match a job you already know, click Verify & lock; the confirm box lists its constants and formulas.

After locking, nobody, admins included, can change its formulas, constants, inputs or gear trains. A Locked badge shows who locked it and when. It can still be calculated, copied with Copy to new draft, and admins can still edit, clear or delete its gear lists and presets.

Delete (admin)

Ask Grok about this
  • Delete machine (red, on the machine page): drafts and locked machines. Built-in routines cannot be deleted. It also offers to delete its gear lists and manual.
  • Gear train sets (admin) box: Remove index/differential train (drafts only), Clear or Delete its gear lists (also on locked machines).
  • Gear inventories: Clear or Delete any list. A train whose list is deleted uses the built-in 20-88 list.

Every delete asks first. Export a backup if you might want it back.

Import / export

Ask Grok about this
  1. Open Import / export. Export saves machines, gear lists and presets (optionally manuals) to a JSON file.
  2. Admins: Import from file loads such a file back (choose whether to replace or add).

Upload data saved before logins (admin)

Ask Grok about this

Before v1.8 each PC kept its own machines and gear lists in its browser. Those do not show up in the shared list by themselves.

  1. On the same PC and browser you used before, sign in as admin.
  2. Open Import / export. If the Upload my local data to the shared database card shows, first click Export to keep a backup.
  3. Click Upload my local data. Machines with the same name in the shared database are replaced.

Troubleshooting

Ask Grok about this

My machine is missing / the list says "None yet"

Ask Grok about this

The list shows machines from the shared database only. A machine made before logins (v1.8) may still be saved only in the browser of the PC it was made on. Use Upload data saved before logins on that PC. If that card does not show, the browser data is gone; use an exported JSON file (Import from file) or enter the machine again.

"🔒 Sign in as admin to add machines"

Ask Grok about this

You are signed in as a viewer (or another non-admin account). Click the line to see your username and role and to sign out / switch account. An admin can change your Change Gear role in QC Form admin.

Sign-in error

Ask Grok about this
  • Wrong username or PIN, or the account is not set up: check the username and PIN (the same as the QC Form); ask the admin if your account is set up.
  • No access to Change Gear (role: none): your account exists but has no Change Gear role; ask the admin.
  • Could not reach / load the shared database: check the internet connection and try again.
  • Your last change was NOT saved to the shared database: reload the page to see what is saved, then try again.

"Something went wrong" banner

Ask Grok about this

Reload the page. If it comes back, note the whole message and the version shown at the end and tell your admin.

Formula guide

Ask Grok about this

The basics

  • A machine has three kinds of names: inputs (what the operator types, like helix angle B or teeth Z), constants (fixed numbers for that machine, like machine constant O) and formulas (calculated from inputs and constants).
  • Names start with a letter and use only letters, numbers and _. Capitals don't matter: z and Z are the same name.
  • A formula can use any input, constant or other formula, in any order, but not itself, even through another formula (the app reports a circular reference).
  • Text inputs (sales order, part description) can't be used in a formula.
  • Machines made with + Add a machine already use the names KIDX (index constant), KDIFF (differential constant), MM (25.4), Z, K, B, D and Q.

Math you can use

  • Operators + - * / ^ and brackets. ^ first, then * /, then + -. Like the old BASIC, -2 ^ 2 is -4; write (-2) ^ 2 for 4. If unsure, add brackets.
  • PI is built in.
  • Angles: SIN COS TAN ATN work in radians; SIND COSD TAND (and ASIND ACOSD ATND) in degrees. Or convert with B * PI / 180.
  • Other functions (one value each): SQR (square root), ABS, SGN, INT, FIX, CINT, ROUND (to a whole number), EXP, LOG (natural log), ASIN, ACOS; and MIN(a, b), MAX(a, b).
  • IF(test, value if yes, value if no). Tests: = <> < > <= >=.

Common patterns

  1. Index ratio: 24 * K / Z (index constant 24 × hob starts ÷ teeth); 30 * K / Z for a machine whose constant is 30. 24, K = 1, Z = 40 gives 0.6.
  2. Differential ratio: O * SIND(B) / D / K for a metric module cutter (D = normal module), (O / 25.4) * SIND(B) * D / K for an inch DP cutter (D = normal DP), with machine constant O set as a constant. O = 11.9367, B = 30, D = 8, K = 1 gives 0.74604375 (metric).
  3. Inch or metric in one formula: IF(Q = 1, O * SIND(B) / D / K, (O / 25.4) * SIND(B) * D / K) - Q = 1 is metric, Q = 0 is inch.
  4. Feed ratio: F / 0.25 = the feed you want ÷ the machine's base feed. 0.25 is only a placeholder: use your machine's own feed constant from its manual.
  5. Build up step by step (easier to check): C = B * PI / 180, then R = O * SIN(C) / D / K.
  6. Hob speed and time: RPM = SF / (DA * PI / 12) (100 SF, 3 in hob: 127.32 RPM), then TIME = (LC / COSD(HELIX)) / (RPM / NT * SN * FEED) minutes per cut.

Tips

  • Give every input an example value, then test the machine with a job you already know the answer to.
  • For a typing mistake the app shows the character position. Look for a missing bracket, a misspelled name, or a function without brackets (SIN B instead of SIN(B)). Other problems (unknown name, circular reference, text input) are named in the message.
  • Once the results match a known job, use Verify & lock.
